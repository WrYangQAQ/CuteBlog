# CuteBlogSystem 博客系统接口文档（前端对接版）

> 说明：本文档根据当前后端 Controller、DTO、Service 实现整理，供 Vue / Axios 前端对接使用。
> Base URL：`http://localhost:5125`

---

## 0. 通用约定

- Content-Type：默认 `application/json; charset=utf-8`
- 文件上传：`multipart/form-data`
- 认证方式：JWT
  - Header：`Authorization: Bearer <token>`
- 角色：
  - 普通用户：`User`
  - 管理员：`Admin`

### 0.1 ApiResponse 结构

大多数业务接口返回 `ApiResponse`：

```json
{
  "success": true,
  "message": "操作成功",
  "data": {},
  "code": 200
}
```

失败示例：

```json
{
  "success": false,
  "message": "请求失败原因",
  "data": null,
  "code": 404
}
```

说明：

- 成功时 HTTP 状态码为 `200`。
- 失败时后端会根据 `code` 映射为对应 HTTP 状态码。
- 部分历史逻辑未显式传入 `code`，失败时可能映射为 `500`，前端应优先展示 `message`。

### 0.2 常见 HTTP 状态码

- `200`：请求成功
- `400`：请求参数错误
- `401`：未登录、JWT 失效或权限校验失败
- `403`：角色权限不足
- `404`：资源不存在
- `409`：数据冲突
- `413`：上传文件过大
- `500`：服务器内部错误

### 0.3 分页结构

部分接口返回 `PagedResult<T>`：

```json
{
  "items": [],
  "totalCount": 12
}
```

## 2. 用户认证接口（`/api/Auth`）

### 2.1 用户注册

**POST** `/api/Auth/register`

**Body：`RegisterDTO`**

```json
{
  "username": "sharky",
  "email": "sharky@example.com",
  "password": "abc123!",
  "nickName": "Sharky"
}
```

**成功响应**

```json
{
  "success": true,
  "message": "用户注册成功！",
  "data": null,
  "code": 0
}
```

**常见失败**

```json
{ "success": false, "message": "注册失败！用户名已被使用！", "data": null, "code": 0 }
```

```json
{ "success": false, "message": "密码只能包含字母、数字和 ! . 这几个特殊字符！", "data": null, "code": 0 }
```

## 10. 前端对接建议

### 10.1 Axios 请求拦截

登录成功后保存 JWT，请求时自动加入：

```http
Authorization: Bearer <token>
```

### 10.2 Axios 响应处理

建议统一兼容大小写字段：

- `success` / `Success`
- `message` / `Message`
- `data` / `Data`
- `code` / `Code`

业务失败时优先展示 `message`。HTTP `401` 时清空登录态并跳转登录页。

### 10.3 上传接口注意事项

文件上传字段名统一为：

```text
image
```

适用接口：

- `POST /api/Auth/avatar`
- `POST /api/Auth/admin/image`
- `POST /api/Articles/cover`

### 10.4 文章点赞注意事项

`POST /api/Articles/{articleId}/like` 是“切换”接口：

- 未点赞时调用：点赞
- 已点赞时调用：取消点赞

接口不会直接返回最新 `liked` 状态，前端可以通过当前用户 `profile.articlesLike` 判断初始状态，并在点击时做乐观更新。
